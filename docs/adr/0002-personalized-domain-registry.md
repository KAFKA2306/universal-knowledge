# ADR-0002：継続的な活動に合わせた分野の再編

**状態：** 試作として採用（2026-10-31）

## 背景

旧版の汎用10分野では、製造技術、半導体投資、論文調査、ソフトウェア開発、ローカルAIなど、継続して扱う課題を整理しにくかった。分野を増やす際に操作の意味が重複すると、抽出結果を比較・評価する基準も曖昧になる。公開リポジトリに実際の資料を置くと、個人情報や業務情報が混入する危険もある。

## 決定

- 継続的に扱う対象を11分野に分け、先に評価する6分野を `core`、残り5分野を `active` とする。この区分は評価の順序であり、精度の優劣を示さない。
- 操作の意味は `domain_packs/*.json`、分野の用途・情報源・禁止事項は `config/domain_registry.json` を正本とする。説明文書はこれらを参照する。
- `kind` と `status` の共通定義を維持する。複数分野にまたがる質問は、当面は人が分野を指定して別々に抽出する。抽出結果を並べただけでは因果関係を確定しない。
- 旧パックの操作名を新パックへ自動変換しない。必要な結果は原文から再抽出する。
- 公開データは架空例と設定に限定する。`requires_review` は確認を促す印であり、承認・実行権限を実装したものではない。

## 影響と残る課題

旧IDや操作名を参照するコードは変更が必要になる。11分野で実際のLLMの抽出精度はまだ測っていない。分野ごとに正解データと評価者を用意する作業が増えるため、まず `core` から評価する。

旧版との対応は [`DOMAIN_MIGRATION.md`](../DOMAIN_MIGRATION.md) に記録した。
