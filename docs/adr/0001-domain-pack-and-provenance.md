# ADR-0001：分野別の操作定義と原文の追跡

**状態：** 試作として採用（2026-10-31）

## 背景

分野ごとにモデルを追加学習する方法では、新しい対象に対応する学習データの準備や学習結果の評価が必要になる。この試作では、操作の定義を設定ファイルに置き、共通の抽出処理を維持する方式を選んだ。LLMの出力には原文にない内容が混じる場合もあるため、引用元を残す。

## 決定

分野ごとにJSONファイルを1つ置き、操作名、その意味、人による確認の要否を管理する。抽出結果の種類は5つ、状態は6つに固定する。採用した記録には、原文と一致する引用、文字位置、出典ID、原文のSHA-256を保存する。不正な形式の候補は拒否する。グラフ出力には出典を含めるが、因果関係は確定しない。

## 制約と変更方法

引用の文字列が一致しても、操作の解釈が正しいとは限らない。同じ引用が原文の複数箇所にあれば、先頭の位置を保存し、人による確認が必要と記録する。実モデルの精度は未測定のため、分野を追加する際には正解データを用意して別途評価する。

操作の意味を変更する場合はパックのバージョンを更新する。出力形式や解釈の互換性に影響する変更は、新しいADRで移行方法も決める。
